# متجر Laseul — تعليمات التشغيل

## هيكل المشروع (منظّم في فولدرات)
```
/
├── index.html          ← الصفحة الرئيسية
├── products.html        ← كل المنتجات (فلترة + ترقيم صفحات)
├── product.html          ← صفحة منتج واحد (?id=...)
├── cart.html              ← السلة
├── checkout.html          ← إتمام الطلب
├── order-success.html     ← تأكيد الطلب + التقييمات
├── admin/
│   └── index.html          ← لوحة التحكم (الرابط: yourdomain.com/admin)
├── css/
│   └── styles.css          ← كل تنسيقات الموقع
├── js/
│   ├── common.js            ← كود مشترك (السلة، البيكسلات)
│   ├── config.js            ← إعدادات المتجر (واتساب، شحن)
│   ├── supabase-config.js   ← مفاتيح الاتصال بـ Supabase
│   ├── products-service.js  ← طبقة الاتصال بالمنتجات والتقييمات
│   ├── home.js               ← كود الصفحة الرئيسية
│   ├── products-list.js      ← كود صفحة كل المنتجات
│   ├── product.js            ← كود صفحة المنتج
│   ├── cart.js                ← كود صفحة السلة
│   ├── checkout.js            ← كود صفحة إتمام الطلب
│   ├── order-success.js       ← كود صفحة التقييمات بعد الطلب
│   └── admin.js                ← كود لوحة التحكم
├── schema.sql / seed.sql   ← أكواد إعداد الداتابيز (خلصت بالفعل، مش جزء من الموقع)
├── vercel.json             ← إعدادات روابط نضيفة (بدون .html)
└── README.md
```

## حالة الإعداد الحالية
✅ مشروع Supabase شغال (`laseul`) مع جداول المنتجات، البيكسلات، والتقييمات
✅ مكان تخزين الصور (`product-images` bucket) شغال
✅ الموقع مرفوع على Vercel، مربوط بـ GitHub، ومربوط بدومين `laseul.shop`
✅ حساب الأدمن جاهز — لوحة التحكم على `/admin`

## الرفع على GitHub
1. **امسحي كل الملفات القديمة** من جذر الـ repo (كل ملفات `.html` و`.js` و`.css` اللي كانت متفرقة، وكمان `app.js` و`products-data.js` القدام لو لسه موجودين — مش مستخدمين خالص)
2. **ارفعي الهيكل الجديد بالكامل** بالفولدرات (`css/`, `js/`, `admin/`) زي ما هو — استخدمي "Add file → Upload files" واسحبي الفولدرات كلها مع بعض، GitHub بيحافظ على شكل الفولدرات تلقائي
3. Vercel هيعمل ديبلوي جديد تلقائي بعد الرفع

## استخدام لوحة الأدمن
الرابط بقى: `laseul.shop/admin` (بدل `/admin.html`)

زي ما هي من قبل، مفيهاش تغيير في المنطق، بس تغيّر مكان الملفات بس.
